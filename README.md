## Overview

Code Typing Challenge makes programming practice part of an active typing exercise. Each session uses a code example rather than ordinary text, allowing learners and developers to improve keyboard fluency while working with recognizable syntax.

Available material spans Python, JavaScript, TypeScript, React, Go, Rust, and SQL. During a challenge, the game provides live words-per-minute and character-accuracy information, making it possible to evaluate both typing pace and correctness.
